Frequently asked questions

Does OmaSales work when the internet is unavailable?

The mobile application is designed around local data and an offline write queue, then synchronizes changes when connectivity returns.

Can OmaSales manage shipping?

Yes. The system supports shipment batches, sea and air shipping workflows, shipping rates, delivery preparation and customer shipping settlement.

Can I use OmaSales on Android and the web?

Yes. The project includes a Flutter Android application and a Flutter Web application backed by the same Flask API.
